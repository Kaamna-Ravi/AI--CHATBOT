AI Chatbot

Introduction

AI Chatbot is a simple web-based chatbot prototype designed to interact with users through a chat interface.

The chatbot allows users to type questions or messages and receive automatic responses.

Objective

The main objective of this project is to create a simple and user-friendly chatbot interface using basic web technologies.

Features

- User-friendly chatbot interface
- Send messages through text input
- Automatic chatbot responses
- Enter key support for sending messages
- Responsive design for mobile and desktop
- Simple and clean user interface
- Predefined responses for common questions

Technologies Used

- HTML
- CSS
- JavaScript

Project Structure

AI-Chatbot/
│
├── index.html
└── README.md

How It Works

1. The user enters a message in the input box.
2. JavaScript reads the user's message.
3. The message is displayed in the chat window.
4. The chatbot checks the message for keywords.
5. A suitable predefined response is displayed.
6. The chat automatically scrolls to the latest message.

Example

User: Hi

Chatbot: Hello! How can I help you?

User: What is your name?

Chatbot: I'm your AI Chatbot.

Installation

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start chatting with the chatbot.
